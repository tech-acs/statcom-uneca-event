# 10th Session of StatCom-Africa

This repository contains the landing page and event information for the **10th Session of the Statistical Commission for Africa (StatCom-Africa)**, organized by the African Centre for Statistics (ACS) of the United Nations Economic Commission for Africa (UNECA).

## Event Details

- **Theme:** "Unleashing the value of data in Africa: making official statistics a true mirror of the continent"
- **Dates:** 19 October - 23 October, 2026
- **Location:** United Nations Conference Centre (UNCC), Addis Ababa, Ethiopia
- **Organizer:** African Centre for Statistics (ACS), UNECA

## About the Event

The Statistical Commission for Africa is the regional equivalent of the Statistical Commission of the Economic and Social Council, which is the highest body in the global statistical system. It serves as the highest decision-making body in Africa responsible for:
- Setting statistical standards
- Developing concepts and methods
- Implementing statistical systems at the national, subregional, and continental levels

### Key Objectives
- Discuss progress and statistical development in African statistical systems.
- Take stock of ongoing global initiatives and mainstream new methodologies.
- Modernize and transform national statistical systems in Africa.

### Expected Outcomes
- Endorsement of the revised African Charter on Statistics.
- Commitments to increase domestic financing for statistical systems.
- Adoption of guidelines for the 2030 round of Population and Housing Censuses.

## Technical Details

This project is a static responsive landing page built with HTML and styled using [Tailwind CSS](https://tailwindcss.com/) via CDN. It includes features like:
- Mobile-responsive navigation and layout
- "Add to Calendar" dropdown for generating calendar events
- Tabbed content for viewing Overview, Agenda, Documents, and Information Notes

### Running locally
Simply open `index.html` in your favorite web browser. No build steps are required.
